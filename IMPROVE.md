**Scan du 2026-09-11**, sur le commit `b5c42fd` (`main`, arbre propre, v1.4.0 publiée).

**Méthode** — signaux mécaniques (`cargo fmt --check`, `clippy --all-targets -D warnings`,
`cargo test --workspace`, `cargo audit`, `npm audit` sur `docs/`, `parite.mjs`) puis six
agents de lecture parallèles : bugs & correctness, sécurité, dette & documentation,
performance & UX, qualité du code engendré, features. Le CLI a été exécuté (`rbs new`,
`add`, `generate`, `doctor`, `upgrade`) sur des projets jetables pour observer sa sortie
réelle. 75 findings bruts, dédupliqués et force-rankés. **Chaque tâche ci-dessous a été
vérifiée dans le code réel** — un finding sans `fichier:ligne` lu a été jeté.

**Rapport avec les autres fichiers** — `IMPROVE_OLD.md` est le backlog du scan précédent
(2026-08-30, v1.1.0) : ses 126 tâches sont toutes faites, aucune n'est reprise ici, et il
est déprécié. `TODO.md` reste le journal clos des cinq premiers jalons. `ROADMAP.md`
porte les jalons et le hors-périmètre.

**Exclusions** — hors périmètre du projet, jamais proposé ici : GraphQL, multi-tenancy,
WebSockets, gRPC, interface d'administration générée, gestion des paiements
(`ROADMAP.md:107-112`). Écartés après lecture : OAuth/OIDC et TOTP (après les clés d'API,
même famille), recherche plein texte (`guides/filtering.md:158` l'écarte : trois moteurs
divergents), `generate crud --from-table` (la spec §3.5 le renvoie à `sea-orm-cli`),
serveur MCP (les tâches 39, 40 et 44 donnent la même surface à un agent sans binaire
nouveau), `rbs new --from <URL>` (réseau dans un CLI qui n'en fait pas).

**Légende** — Tags : `[Bug]` `[Sécu]` `[Perf]` `[UX]` `[Dette]` `[Doc]` `[Feature]`
`[Arch]`. Difficulté : Easy (< 1 j) · Medium (1-3 j) · Hard (3-10 j). Les chemins
`templates/…` s'entendent sous `crates/rbs-cli/templates/`, les autres sous `crates/rbs-cli/src/`
