# rbs 1.0.1 — rien à faire

Aucune rupture, aucun changement de comportement. Cette version corrige ce que la
publication de la 1.0.0 a rendu visible et que le code ne pouvait pas dire :

- les deux paquets paraissaient sur crates.io sans README, aucun manifeste n'en déclarant
  et le fichier du dépôt vivant hors du paquet ;
- la documentation imposait encore `--core-path` comme étape du parcours, contournement
  d'un noyau non publié — il ne l'est plus depuis la 0.4.0.

`cargo update -p rbs-core` suffit. Votre code ne bouge pas.
