# `rbs test` — plan d'implémentation

> **Pour les agents :** sous-skill requis : `superpowers:subagent-driven-development`.
> Les étapes se suivent en cases `- [ ]`.

**But :** `rbs test [FILTRE] [-- <args libtest>]` monte ce que `rbs dev` monte (compose,
attente de la base, migrations) sans le serveur, puis lance
`cargo test --workspace --no-fail-fast [FILTRE] -- --include-ignored [args…]` et rend son
code de sortie tel quel.

**Architecture :** `dev::plan` ne produit plus que les étapes communes ; `dev::run` y
ajoute `Step::Server`, le nouveau module `test` y ajoute `Step::Tests(arguments)`.
`dev::start` sait exécuter les deux ; `dev::render` affiche les deux. L'échec de
`cargo test` devient `dev::Error::Tests { code }`, dont `exit_code()` rend le code brut.

**Spec :** `docs/superpowers/specs/2026-09-13-lot-features-p2-design.md`, section « 34 ».

## Contraintes globales

- `CLAUDE.md` racine : commentaires = *pourquoi* ; commits Conventional Commits en
  français, sans identifiant de tâche, sans `Co-Authored-By` ni `Claude-Session`, corps
  avec `Vérifications :`.
- La commande de tests est **celle de la CI engendrée**
  (`templates/features/ci/.github/workflows/ci.yml.jinja:80`) :
  `cargo test --workspace --no-fail-fast -- --include-ignored`.
- Le code de sortie de `cargo test` est propagé **tel quel** (101 pour un test rouge).
- Tests lents : un binaire par commande, `--no-fail-fast` avant le `--`, sortie
  redirigée vers le scratchpad sous un nom préfixé `g3-`. Nom du projet engendré
  distinct de `demo-api` (neuf suites l'emploient déjà dans la même cible).
- Doc bilingue dans le même commit ; `npm run build` sous `docs/`.

`dev/mod.rs` :
- `Step::Tests(Vec<String>)` documentée « Lancer `cargo` avec ces arguments : les tests
  du workspace ».
- `plan()` : retirer `steps.push(Step::Server)` ; commentaire de tête : chaque commande
  ajoute sa dernière étape.
- `run()` : `let mut steps = plan(&root)?; steps.push(Step::Server);`.
- `start()` : bras `Step::Tests(arguments)` →

```rust
Step::Tests(arguments) => {
    let arguments: Vec<&str> = arguments.iter().map(String::as_str).collect();
    crate::cargo::run(root, &arguments, &variables, false).map_err(|error| match error {
        crate::cargo::Error::Lancement(source) => Error::Cargo(source),
        crate::cargo::Error::Statut(code) => Error::Tests { code },
    })?;
}
```

- `render()` : `Step::Tests(arguments) => format!("  tests       cargo {}", arguments.join(" "))`.
- `Error::Cargo(#[source] io::Error)` — « cargo n'a pas pu être lancé : {0} » ;
  `Error::Tests { code: i32 }` — « `cargo test` a échoué (code {code}) ».
- `exit_code()` : `Tests { code } => *code`, sinon `1` ; commentaire : une CI distingue un
  test rouge (101) d'une commande qui n'a pas pu démarrer.
- `render`, `patience`, `start` passent `pub(crate)`.

`test.rs` :

```rust
//! `rbs test` : les tests du projet, dans l'état où la CI engendrée les lance.
//!
//! Les étapes sont celles de `rbs dev` sans le serveur — la base montée et migrée est
//! celle que les tests joignent — puis la commande même de la CI.

use std::path::Path;

use crate::dev::{self, Step};
use crate::metadata;

pub(crate) fn arguments(filtre: Option<&str>, libtest: &[String]) -> Vec<String> {
    let mut arguments: Vec<String> = ["test", "--workspace", "--no-fail-fast"]
        .map(String::from)
        .into();
    arguments.extend(filtre.map(String::from));
    // `--include-ignored` : les tests qui joignent la base sont `#[ignore]` pour qu'un
    // `cargo test` nu reste rapide ; ici la base vient d'être montée, ils ont tout lieu
    // de tourner.
    arguments.extend(["--".to_string(), "--include-ignored".to_string()]);
    arguments.extend(libtest.iter().cloned());
    arguments
}

pub(crate) fn plan(root: &Path, filtre: Option<&str>, libtest: &[String]) -> Result<Vec<Step>, dev::Error> {
    let mut steps = dev::plan(root)?;
    steps.push(Step::Tests(arguments(filtre, libtest)));
    Ok(steps)
}

pub(crate) fn run(directory: &Path, filtre: Option<&str>, libtest: &[String]) -> Result<(), dev::Error> {
    let root = metadata::project_root(directory)?;
    let steps = plan(&root, filtre, libtest)?;
    crate::ui::info(&dev::render(&steps));
    dev::start(&root, &steps, dev::patience(&steps))
}
```
