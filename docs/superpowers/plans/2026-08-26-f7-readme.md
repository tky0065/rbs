# README FR + EN — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:subagent-driven-development`
> ou `superpowers:executing-plans`. Les étapes sont en cases à cocher.

**Goal:** Un README qui dit ce qu'est rbs, montre ce qu'on obtient en trois commandes, et
énonce sans détour l'absence de promesse semver avant la v1.0.

**Architecture:** Le dépôt n'a **aucun** README à ce jour — c'est la première page que
voit un visiteur, et la seule qui doive tenir sans le site. Elle est donc autonome : pas
de directive `file=`/`region=`, que le plugin Docusaurus ne traite pas hors du site. Les
extraits y sont donc écrits, ce qui les rend faillibles — d'où la contrainte de n'en
mettre qu'un, court, et de le recopier d'un fichier réel.

La convention bilingue est déjà posée par `CONTRIBUTING.md` / `CONTRIBUTING.fr.md` : le
fichier anglais porte le nom nu, le français le suffixe `.fr`. Chacun ouvre sur un lien
vers l'autre.

Le critère `✓` est explicite et unique : « mentionne explicitement l'absence de promesse
semver avant la v1.0 ». Ce n'est pas une note de bas de page — c'est un avertissement que
le lecteur doit croiser avant de décider d'installer.

**Spec:** `docs/superpowers/specs/2026-08-25-rbs-design.md` ; `ROADMAP.md` pour le
périmètre et le hors-périmètre.

## Global Constraints

- Branche dédiée `f7-readme`, jamais `main`.
- Bilingue dans le même commit : `README.md` et `README.fr.md`.
- **Interdiction d'écrire dans `examples/hello-crud`** (propriété de F4 et F6) et dans
  `docs/` (propriété de F3, F4, F5, F6).
- Toute commande citée est exécutée avant d'être écrite.
- Aucun lien mort : les liens relatifs pointent vers des fichiers qui existent.
- Conventional Commits, sujet en français, sans identifiant de tâche.

## File Structure

- Create: `README.md`
- Create: `README.fr.md`
- Ne pas modifier : `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `ROADMAP.md`, `TODO.md`
